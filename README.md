# 🔧 C# Functions & Git Mastery Demo

Welcome to a hands-on project combining **C# programming fundamentals** with **Git version control basics**. This repository includes a simple C# console application demonstrating how **functions work in C#**, along with Git operations to simulate a real-world collaborative development workflow.

---

## 📌 Project Overview

This project features a basic C# program where you'll explore:

- ✅ **Function definitions and calls**
- ✅ Parameter passing and return values
- ✅ Basic control flow using functions

But that’s not all — it also walks through **essential Git operations** to help you understand the core of collaborative development.

---

## 🧠 What You'll Learn

### 🖥️ C# Concepts
- Writing and organizing **C# methods**
- Return values and void methods

### 🧰 Git Concepts Demonstrated
- ✅ `git commit` – Track and save your progress
- ✅ `git push` – Upload changes to your GitHub repo
- ✅ `git pull` – Sync with the latest updates
- ✅ `git revert` – Undo changes like a pro
- ✅ `git branch` – Work on new features without affecting `main`
